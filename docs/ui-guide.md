# UI 구성과 접근성

## 추천과 실제 선택

madi에는 **Radix Primitives + 프로젝트 소유 React 컴포넌트·CSS 디자인 시스템**을 선택했습니다. 대화상자와 프로필 메뉴처럼 포커스·키보드 동작이 중요한 요소는 Radix를 사용합니다. Radix는 접근성 패턴과 포커스 관리, 스타일을 직접 제어할 수 있는 기반을 제공합니다. [Radix 공식 소개](https://www.radix-ui.com/primitives/docs/overview/introduction)

사용자가 제시한 shadcn/ui도 컴포넌트 소스를 직접 관리하며 제품에 맞게 바꾸는 접근에 적합합니다. 현재 구현은 shadcn CLI로 생성한 프로젝트라고 표기하지 않고, 실제 사용한 Radix와 자체 컴포넌트를 명시합니다. [shadcn/ui 공식 소개](https://ui.shadcn.com/docs)

단순 선택은 브라우저의 기본 select를 사용하고 한국어 접근성 이름을 연결했습니다. 다중 선택·DB 속성 변경·모바일 드롭다운은 실제 Chromium에서 옵션 선택과 저장·새로고침을 시험합니다. 라이브러리 사용만으로 모든 접근성이 보장된다고 간주하지 않습니다.

## 읽기와 탐색

- 한국어 Noto Sans KR 폰트를 이미지에 포함하므로 외부 폰트 서버가 필요 없습니다.
- 주요 본문과 입력은 16px를 기준으로 하고 개인화 화면에서 글자 크기와 문서 폭을 조정합니다. 날짜·버전 등 보조 표시는 구분된 크기를 사용합니다.
- 짙은 녹색 탐색 영역, 차분한 배경, 여백과 대비로 문서와 조작을 구분합니다. 라이트·다크 모드를 제공합니다.
- 관리자 `/admin`과 사용자 `/app`, 개인 설정·키 관리 영역을 분리합니다. 관리자 권한이 없는 사용자는 관리자 메뉴를 보지 않습니다.
- URL에 선택 메뉴·뷰·검색 조건을 보존합니다. 개인 설정과 트리 상태는 서버에도 저장하고, 늦게 도착한 이전 문서·워크스페이스 응답은 현재 화면에 적용하지 않습니다.
- 메뉴 스크롤바는 탐색 영역과 색을 맞춥니다. 모바일 표는 글자를 한 글자씩 줄이지 않고 필요한 경우 표 영역 안에서 가로로 스크롤합니다.

## 제품 표시와 오프라인 자산

로그인 화면과 프로필 메뉴에서 서비스 버전을 확인합니다. 로고는 지식이 연결되는 마디를 형상화한 SVG이며 favicon과 설치 아이콘을 함께 제공합니다. React·편집기·그래프·수식·다이어그램·폰트·아이콘을 서비스 이미지에 포함합니다.

프로필 메뉴의 **오픈소스 고지**는 서비스에 포함된 `/licenses.txt`를 엽니다. 프로덕션 의존성의 라이선스와 NOTICE 원문을 함께 배포하며 `/licenses-manifest.json`에 구성과 해시를 기록합니다.

## 검증 범위

데스크톱과 390px 모바일에서 주요 버튼·선택·폼·메뉴·새로고침·오류 상태를 실제 브라우저로 검사합니다. 키보드 포커스, 모달 닫기, 문서 초안 보존, 비동기 응답 경쟁을 별도 회귀 시험으로 확인합니다. 화면별 증거는 [실제 화면 갤러리](https://hkjang.github.io/madi/screenshots.html)에 제공합니다.
